# Admission Predictor AI

A hybrid React + Vite portfolio project that estimates university acceptance chances using academic and extracurricular inputs.

## Features
- Hybrid serious + AI-dashboard design
- GPA, SAT, IELTS, extracurricular, and awards inputs
- Predicted chances for multiple universities
- Radar chart for profile shape
- Ranked admissions results
- Portfolio-friendly layout

## Tech Stack
- React
- Vite
- Recharts
- Lucide React

## Run Locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
